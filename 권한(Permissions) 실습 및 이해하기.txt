권한(Permissions) 실습 및 이해하기 / git bush

권한 기호의 의미 (r, w, x)
r (Read, 읽기) : 파일 내용을 볼 수 있는 권한 (숫자 4)
w (Write, 쓰기) : 파일 내용을 수정/삭제할 수 있는 권한 (숫자 2)
x (Execute, 실행) : 프로그램을 실행할 수 있는 권한 (숫자 1)
- (없음) : 권한이 없음 (숫자 0)

ls -l을 입력했을 때 나오는 맨 앞 10자리 문자(예: -rw-r--r--)는 다음과 같은 구조입니다:
맨 첫 글자: -는 일반 파일, d는 디렉터리(폴더)
다음 3글자: 소유자(User) 권한 (예: rw- -> 읽기/쓰기 가능 = 4+2 = 6)
다음 3글자: 그룹(Group) 권한 (예: r-- -> 읽기만 가능 = 4)
마지막 3글자: 기타 사용자(Others) 권한 (예: r-- -> 읽기만 가능 = 4)
따라서 -rw-r--r--을 숫자로 표기하면 644가 됩니다!
1) 파일 권한 변경 실습
# 1.practice 폴더 안에서 my_file.txt 생성
hello@Desktop-1 MINGW64 /c/ai_codyssey
$ touch my_file.txt
# 2.현재 파일 권한 확인
# (보통 -rw-r--r-- 형태로 출력됨)
hello@Desktop-1 MINGW64 /c/ai_codyssey
$ ls -l my_file.txt
-rw-r--r-- 1 hello 197609 0 Jul 30 20:30 my_file.txt

# 3.권한 변경: 모든 사용자에게 읽기/쓰기/실행 권한 부여 (755 설정)
# 7(읽기4+쓰기2+실행1) 5(읽기4+실행1) 5(읽기4+실행1)
hello@Desktop-1 MINGW64 /c/ai_codyssey
$ chmod 755 my_file.txt
# 4.변경된 권한 확인
hello@Desktop-1 MINGW64 /c/ai_codyssey
$ ls -l my_file.txt
-rw-r--r-- 1 hello 197609 0 Jul 30 20:30 my_file.txt
# (-rwxr-xr-x 형태로 변경된 것을 볼 수 있음)

2) 디렉터리(폴더) 권한 변경 실습
# 1. sub_dir 폴더 생성
hello@Desktop-1 MINGW64 /c/ai_codyssey
$ mkdir sub_dir
# 2. 현재 폴더 권한 확인
hello@Desktop-1 MINGW64 /c/ai_codyssey
$ ls -ld sub_dir
drwxr-xr-x 1 hello 197609 0 Jul 30 20:33 sub_dir/
# 3. 권한 변경: 소유자만 읽고 쓰기 가능하도록 600으로 변경
# 6(읽기4+쓰기2) 0(없음) 0(없음)
hello@Desktop-1 MINGW64 /c/ai_codyssey
$ chmod 600 sub_dir
# 4. 변경된 권한 확인
hello@Desktop-1 MINGW64 /c/ai_codyssey
$ ls -ld sub_dir
drwxr-xr-x 1 hello 197609 0 Jul 30 20:33 sub_dir/
# (drw------- 형태로 변경된 것을 볼 수 있음)
